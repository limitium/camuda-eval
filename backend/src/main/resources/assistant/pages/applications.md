**Applications** — the home page. Every application this instance deploys rules to, with what each runs now on this environment: a tag (for example `v1.0.0`, "running"), a work space's draft ("draft live"), "nothing deployed", or "problem" when its topic cannot be read or its domains run different commits.

Opening an application shows what it runs (to look at and try), lets you start a work space from it, deploy a tag to it, and see its history. Deploying happens on the application's page, not here.

The button at the bottom right, **Go to work spaces**, leads to where rules are changed (authoring instances only).
