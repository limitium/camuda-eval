**Work spaces.** Rules change in work spaces. A work space is one branch, so it can be continued on any instance. Listed: your own (**Continue**), colleagues' work spaces here, and those worked on elsewhere (**Continue … here**).

**Start a new work space** (bottom right) starts one: name it and pick what it builds on in the graph — a branch by its label (its newest commit) or any commit. Building on main or a release branch makes a `feature/…` branch; building on a tag makes a `hotfix/…` branch that merges into that tag's release branch.
