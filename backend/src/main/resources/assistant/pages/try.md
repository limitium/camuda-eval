**Try it in an application** — the step after committing, on dev only. Publishing puts this work space's last commit of the domains an application reads onto that application, so it uses them straight away — replacing what it ran until a release is deployed there again (or **Put the last release back** on the application's page). Every test runs first.

How: choose the application, then press the **Publish to** button (it names the application). Afterwards the **See** button shows what it runs, and **Go on to merging** continues. **Skip to merging** leaves trying out.
