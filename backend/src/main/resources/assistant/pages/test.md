**Test** — step 2 of a work space. Every changed table is run against its own test cases; failing cases are listed with what they expected and what the table gave. Changes can be committed with failing tests, but they cannot be merged until the tests pass.

**Run the tests** (bottom right) runs them; the **Open … to fix it** button opens a failing domain. When all pass, **Review and commit changes** goes to the commit step. Test cases themselves are written on the domain's tables, under each table.
