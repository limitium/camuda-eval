**Start a new work space.** Name it and pick, in the graph, what it builds on: a branch by its label (its newest commit) or any single commit. The screen says which branch it becomes (`feature/<you>/<name>`, or `hotfix/<you>/<name>` when it builds on a tag) and which branch it will merge into. Then **Start the work space** (bottom right).

Which to pick: new work for the next release → main. A change for a release being stabilised → that release branch. A fix to what production runs → its tag.
